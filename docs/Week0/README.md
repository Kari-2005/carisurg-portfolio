# Week 0 Documents

This folder contains written reports, figures, and supporting evidence from Week 0 of the CariSurg MedTech Pathways programme.

Week 0 focused on basic clinical data cleaning, exploratory analysis, visualisation, and early clinical reasoning using the emergency triage dataset.

## Folder Contents

- `figures/` contains plots and graphs generated during the Week 0 analysis.
- `evidence/` contains screenshots used as supporting evidence for setup, GitHub work, or submissions.
- PDF files contain written explanations, clinical reflections, or assignment reports.

## Notes

The original Week 0 dataset is not stored in this public repository because it is healthcare-related data. The dataset should be stored locally or in a private Google Drive location when running the notebooks.
