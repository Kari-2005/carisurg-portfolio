# Docs

This folder contains written documents, reports, proposal updates, figures, screenshots, and supporting evidence for my CariSurg MedTech Pathways portfolio.

## Purpose

The `docs/` folder is used for non-notebook deliverables that support the project, including memos, PDFs, proposal documents, risk analysis files, workflow diagrams, visualisations, and submission evidence.

## Contents by Week

### Week 0

Week 0 documents include early clinical data cleaning outputs, visualisation evidence, clinical explanations, and supporting files from the introductory emergency triage data tasks.

### Week 1

Week 1 documents include the literature review, AI-assisted triage research summaries, proposal materials, and Vancouver-style references.

### Week 2

Week 2 documents include evidence of repository setup, GitHub workflow, pull request screenshots, and updated proposal material using managed citations.

### Week 3

Week 3 documents include the ED triage workflow diagram, systems-thinking notes, clinical stakeholder considerations, and proposal updates related to workflow constraints.

### Week 4

Week 4 documents include the AI safety and ethics risk register, healthcare AI harm case analysis, risk memo, and proposal updates related to risk analysis.

### Week 5

Week 5 documents include the feasibility memo, missingness table, data-quality visualisations, exploratory analysis outputs, correlation summaries, and the top-10 feature shortlist for Week 6 baseline modelling.

Key Week 5 files include:

- `Week5_Feasibility_Memo_AnsarahMohammed.pdf`
- Week 5 data-quality visualisations
- Week 5 missingness and correlation summary files

## Data Privacy Note

This folder may include summary figures, reports, and documentation generated from clinical or healthcare-related datasets. Raw healthcare datasets are not uploaded publicly unless explicitly permitted by the programme or dataset provider.

Only derived outputs, written summaries, and non-identifiable evidence are included here for review.
